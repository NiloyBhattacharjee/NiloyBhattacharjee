## Hi, I'm Niloy 👋

I'm a full stack developer based in Sydney. Most of my work is on AWS with Python and TypeScript: data pipelines, backend services and the occasional internal dashboard.

I got into simulation while working with a team of researchers on discrete event models for mining supply chains, and I've been building in that space ever since.

- **[surgesim](https://github.com/NiloyBhattacharjee/surgesim)** – a discrete event simulator for cloud and distributed systems, inspired by JaamSim. Runs on any OS, with a web version and a desktop version planned. Packages are published on npm under `@chronon-sim`.
- **Mitu** – an AI assistant for small shops that sell through Facebook, Instagram and WhatsApp DMs. It answers price, size, stock and delivery questions, takes orders (cash on delivery or bKash), understands voice notes and photos, and hands the chat to a person when it should. One install runs many businesses, each with its own staff dashboard. FastAPI, React, Bedrock / Anthropic API / Ollama, Docker.
- **JaamSim** – improving the Event Viewer (Future Events tab) for the open-source JaamSim simulator.
- **Multi-tenant ERP** – a long-term learning project, starting with an inventory module. dbt + Snowflake, runs locally for now, moving to AWS later.
